# Content Structure

## Scope
This document defines how the `Content/` folder is organized for this solo Unreal project.
It focuses on assets and Blueprints only.

## Principles
- Keep assets close to the feature that uses them.
- Put shared assets in a `Shared/` folder at the root of `Content/`.
- Avoid cross-feature references when possible.
- Prefer predictable, repeatable folder names.

### Feature Folder Rules
- Each feature folder owns its own Levels, Blueprints, and feature-specific assets.
- Avoid putting feature-specific assets in shared root folders.
- Use the same subfolder names across features when possible.

### Shared Folder Rules
- Use `Shared/` for assets used by multiple features.
- Keep shared assets clean and well named to avoid confusion.

### ThirdPerson Template
- Keep `ThirdPerson/` as a reference or migrate useful assets into `Shared/`.

### Unreal Generated Folders
- `__ExternalActors__/` and `__ExternalObjects__/` are managed by Unreal. Do not edit.

## Future C++ Convention (Lightweight)

