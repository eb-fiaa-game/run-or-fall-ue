Use these prefixes consistently:
## Asset Prefixes

- Optional sublevels: `Lvl_<Feature>_<Sub>`
- Maps: `Lvl_<Feature>` (example: `Lvl_Combat`)
## Level Naming

- Prototype folder: `LevelPrototyping`
- Shared folders: `Characters`, `Input`, `UI`, `VFX`, `Materials`, `Textures`, `Meshes`, `Data`
- Feature folders: `Variant_<Mode>` (example: `Variant_Combat`)
## Folder Naming

- Use underscores only to separate prefix from name.
- Keep names short but descriptive.
- Use clear prefixes for asset types.
- Use PascalCase for folder names.
